- 판단 근거: 사용자가 알려 준 전공·진로를 따르고 가상 회사·수상·숙련도는 정리했다. 관심 이유와 계획은 검토 가능한 초안이다.
- 검증 대상: 실제 배포에서 이름·메뉴·이미지·출처·재생/정지·모바일 화면을 확인한다. 결과는 별도 검증 기록으로 남긴다.

- 실제 요청: “3D로 요즘 멋있는 웹사이트 … 고급스러운 MRI 이미지”, 후속 제약 “배경은 건드리지마”.
- 반영: 기존 페이지·섹션 배경색을 보존하고 MRI 장비 콘셉트 렌더, 큰 제목, 마우스/방향키 기울기, 효과 끄기, 초기화, 모션 감소 설정 대응을 추가했다.

- 활동의 목적·역할·과정·한계는 펼침 영역에서 모두 확인 가능하다. 미완성 연구 프로젝트는 추가하지 않았다.
