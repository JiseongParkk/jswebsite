# 사이트 제작 이후 제출 준비

현재 범위는 개인 웹사이트 제작·배포이다. 최종 PDF와 LMS 제출은 별도 단계이다.

## 공개 화면

- 이름·전공·짧은 소개: `#about`.
- 관심과 이유: `#interests`.
- 실제 활동의 기간·상태·목적·역할·과정·결과·한계: `#activity`.
- 현재 도구와 사용 사례: `#skills`.
- 학습 목표와 다음 행동: `#roadmap`.
- 외부 이미지·테마 출처: `#sources`.
- 추후 프로젝트는 완성·진행 상태를 정확히 표시하고 실제 본인 수행 자료로 추가한다.

## 동작 증빙

1. HTTPS 공개 접속과 최종 main SHA에 해당하는 build/deploy 성공을 확인한다.
2. 1440px·390px 화면은 파일로 저장하고 URL·시각·폭·브라우저 버전·그림 번호를 기록한다. 768px와 200% 확대도 확인한다.
3. 배포·자산 경로·메뉴/링크·반응형·키보드 다섯 영역을 각각 포함한 검증표를 작성한다.
4. CT 밝기 조절 및 초기화, 재생·일시정지·초기화를 실제 조작한다.
5. 유효 커밋 50개 이상을 최종 main 이력에서 집계한다. 단순 원본 업로드·빈 커밋 등은 제외한다.

## 보고서에 필요한 정보

- 학번·이름·GitHub ID, 공개 사이트와 저장소 URL.
- 최종 main 전체 SHA, 커밋 URL, 같은 버전 Actions URL과 상태.
- 도구·버전, 테마 원본 URL, 설치·실행 방법과 수정 위치.
- 실제 변경 2건의 전후·파일 경로·확인 결과.
- 오류 해결 또는 기능 개선 1건의 관찰·수정·재확인.
- 실제 AI 활용 2건의 요청·응답·본인 판단·반영 파일·검증·한계.
- 후보/제외/유효 커밋 수, 집계 범위, 제외 이유와 이력 링크.
