# 출처와 제작 범위

## 원본 테마

- Toha: https://github.com/hugo-toha/toha / MIT License.
- 원본 `LICENSE`는 저장소 루트에 유지한다. Hugo module은 이 저장소의 로컬 테마 소스를 사용한다.
- 개인 화면: `exampleSite/layouts/index.html`, `exampleSite/layouts/partials/portfolio/`.
- 스타일: `exampleSite/assets/styles/portfolio/`. 개인 콘텐츠: `exampleSite/data/portfolio/`.
- 개인 홈페이지 기능은 `params.medicalPortfolio.enable`로 제어한다. 원본 테마 홈페이지는 fallback으로 보존한다.

## 외부 자료

- MRI: [상세 출처](media/mri.md), everyone's idle, CC BY-SA 2.0.
- CT: [상세 출처](media/ct.md), Mikael Häggström, M.D., CC0 1.0.
- 두 이미지는 원본 파일 그대로 저장하며, 사이트에 저작자와 이용 조건을 표시한다.
- MRI는 비율을 유지해 표시한다. CT 밝기 조절은 브라우저 표시만 조절한다.
- NIBIB MRI 교육 자료: https://www.nibib.nih.gov/science-education/science-topics/magnetic-resonance-imaging-mri
- NIBIB CT 교육 자료: https://www.nibib.nih.gov/science-education/science-topics/computed-tomography-ct

## 직접 구성·AI 보조 제작

- 신호 모양의 SVG 마크, CT 획득 SVG 개념도와 재생 스크립트는 이 사이트를 위해 제작했다.
- CT 그림은 환자 데이터 기반의 시뮬레이션이 아닌 단순한 개념도이다.
- 소개·관심 분야·학습 계획은 사용자가 제공한 본전공과 진로 방향을 바탕으로 AI 보조를 활용해 구성한 초안이다. 사용자의 실제 경험과 의도에 맞게 계속 수정한다.
- 실제 활동에는 현재 수행 중인 웹사이트 구축만 기록했다. 수상, 회사 경력, 자격증, 숙련도 수치는 생성하지 않았다.
- 실험 데이터, 미완성 프로젝트와 개인 연락처는 본 사이트 콘텐츠에 포함하지 않았다.
